# Go deterministic core contract

`internal/domain` owns exact decimal values and the explicit wire action enum (zero is invalid, semantic actions are 1–6). Input coefficients have at most 128 digits and scale at most 36. Values are immutable: arithmetic always copies private `math/big.Int` state. JSON decimals are canonical strings, with trailing zeros removed. Monetary equality uses numeric decimal comparison, not source spelling. Raw venue strings remain in the public recorder for checksums.

Addition, subtraction and products are exact within an internal 512 digit, 144 scale envelope. Division explicitly produces at most 72 fractional places and defaults to truncation toward zero. Tick and lot rounding use explicit mathematical floor/ceiling. The compiler divides at higher precision than the supported lot scale and floors child quantity; fee reservations use the larger configured fee rate. Arithmetic beyond the internal envelope fails loudly rather than wrapping or converting to float. The RPC boundary must reject unsupported external inputs and contain arithmetic failures.

Relative times are signed integer nanoseconds. Legacy written seconds import with nearest rounding, ties to even; negative or overflowing time is rejected. Receipt order stays stable. Missing noninitial receipt indices receive the input slice position. Equal-time events execute in receipt order before arrival and then cancellation. Constructors reject timer addition overflow. Replay is deterministic and must have one serialized owner per engine; it does not perform network, wall-clock or database operations.

The Go environment is `LiquidityLab-SpotExecution-v1`, report `report-v1`, compiler `six-action-v1`, features `compact-v1` with the 20 ordered names exported by `replay.ObservationFields`. Monetary report numbers are exact strings. Features and rewards alone use binary floats. Derived feature acceptance starts at two float32 ULPs; fixture terminal reward/objective comparisons currently use absolute tolerance `1e-10`. Canonical JSON and time formatting cause dataset hashes to differ from legacy Python hashes.

`go test ./internal/domain ./internal/execution ./internal/replay ./internal/marketdata ./internal/venue/kraken` checks the four Python reference cases from `golden.json`, including every economic field, fills, order outcomes, decisions, status, processing count and final time. Additional cases cover fee bounds, duplicate executions, atomic rejection, debt, timer ties, invalid feeds, unresolved settlement, frozen residual prices, completion finality, features, reset and engine isolation. A seeded decimal fuzz target is included; a sustained fuzz campaign and throughput/load validation remain separate gates.

The public recorder is transport neutral: it validates and normalizes captured raw frames and accepts elapsed nanoseconds from the caller. A live WebSocket capture/reconnect loop is not included in this bounded milestone. There is no private order submission in these packages.
